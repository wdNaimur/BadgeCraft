# BadgeCraft Project Documentation

Welcome to **BadgeCraft**! This directory contains documentation for the learning project designed to teach modern Shopify app development using React Router v7, Shopify CLI, Prisma, and Theme App Extensions.

## Navigation

* **[Project Overview](project-overview.md):** What we are building, why we are building it, and the core learning goals.
* **[Architecture & File Structure](architecture.md):** Deep dive into the codebase structure, Shopify API communications, and data flows.
* **[Development Roadmap](roadmap.md):** The sequential phases of implementing features from start to finish.

## Tech Stack Overview

* **Frontend:** React Router v7, Shopify App Bridge v4, Shopify Polaris UI / Web Components
* **Backend:** Node.js, React Router Server Actions/Loaders
* **Database:** Prisma ORM, SQLite (local development)
* **Shopify Integration:** Shopify Admin GraphQL API, Theme App Extensions (Liquid/HTML/JS)
